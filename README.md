# Azaami Store Starter

This is a simple shopping app starter built in plain HTML, CSS, and JavaScript.

Features included:
- Product grid
- Search bar
- Category filters
- Add to cart
- Cart drawer with subtotal
- Mobile responsive layout

How to run:
1. Open `index.html` in a browser, or
2. Serve the folder with a local server:

```bash
python3 -m http.server 8000
```

Then open: http://localhost:8000

This is a good starting point for a full e-commerce app.
